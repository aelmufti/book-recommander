# Book Finder API

API de recherche de livres français avec 56k+ livres.

## Déploiement sur Render

1. Connecter ce repository à Render
2. Choisir "Web Service"
3. Configuration automatique via `render.yaml`

## Endpoints

- `POST /recommend` - Recherche de livres
- `GET /` - Informations sur l'API
- `GET /health` - Status de santé
- `GET /docs` - Documentation Swagger

## Dataset

56,323 livres français avec métadonnées complètes.
